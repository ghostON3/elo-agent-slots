agentic-os · slot-first

Agents sit into slots.
They find their own work.

The standard pattern pre-assigns every agent a task before spawning it. This inverts that: the slot is the persistent identity, the agent is ephemeral. You update a slot's preheat config once — every future agent inherits it.

The inversion

↓agent browses /orders
↓claims one · reads /preheat · executes

slot-browser-cron.mjs
// every 30s: find idle seats + pending work, pair them async function tick() { const idleSlots = await eloApi('GET', '/api/ops/runtime-slots?state=idle') const orders = await eloApi('GET', '/api/agentic-os/orders?status=queued') if (!idleSlots.length || !orders.length) return // nothing to pair const slot = idleSlots[0] const order = orders.sort(by('priority', 'desc'))[0] // write a 2-field brief: entry_point only, no pre-assigned task await writeBrief(slot, order) await eloApi('POST', '/api/dispatch', { briefPath, slot }) // agent wakes up, reads /orders, picks one, reads /preheat, executes }

1M blueprint slots.
